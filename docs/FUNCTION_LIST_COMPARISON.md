# NewPipe function list comparison: Android vs HarmonyOS

- **Source:** NewPipe for Android 0.29.1 (build 1015), 847 functions.
- **Target:** NewPipe for HarmonyOS (`etspworks/NewPipe-HarmonyOS` main).
- The Android function list was extracted from the app's source code, layouts and documentation.
- Each Android function was then looked for in this port: on a HUAWEI Mate 60 with a screenshot, and in
  the port's source code where a screenshot could not settle it.
- ✅ = the app has the function, ❌ = it does not.
- The levels follow the Function List format of `function-list-pipeline`. Level 1 Module is a screen,
  panel, menu or notification of the app; Secondary Module, Three-level module and Level 4 Module are the
  elements tapped from it, one level per tap. A row ends at its own level, so the deeper columns stay
  empty. An element that opens further elements has its own row first, with its name repeated in the next
  column; anything deeper than Level 4 is joined into Level 4 Module with `>`.
- As in the Function List workbook, a module, element or page is one merged cell over all the rows of
  its group. A markdown table cannot merge cells, so the two tables below are written in HTML.
- The functional description comes from the Android list. The port has no function list of its own, so
  there are no HarmonyOS-only rows (– in the summary).
- 817 rows: 764 in both, 53 Android only.
- 30 Android functions were left out of the comparison; they are listed after the table.
- The same tables are in the workbook [FUNCTION_LIST_COMPARISON.xlsx](FUNCTION_LIST_COMPARISON.xlsx),
  with each group as merged cells.
